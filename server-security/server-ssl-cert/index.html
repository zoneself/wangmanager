证书过期导致站打不开，这种事怎么避免

正月十五一个客户网站弹「连接不是私密连接」，证书过期两天，那几天还在投Google广告，落地页进不去钱照烧。靠人记到期日不靠谱，我用的是自动续期加一道监控。

发布于 2026-11-22 更新于 2026-11-25 王经理服务器与安全

有年正月十五，一个做包装机械的客户紧急找我，说网站打不开了，浏览器弹「您的连接不是私密连接」。我一看，SSL证书过期两天了。他用的是免费证书，三个月一续，上次是年底忙忘了。更糟的是那几天他在投Google广告，落地页进不去，广告费照烧，询盘一个没有。他心疼得不行，问我有没有办法让这事永远不发生。

证书过期是网站最不该出、却最常见的事故之一。原因很简单：不管是付费还是免费证书，都有有效期。免费的（Let's Encrypt那类）通常三个月，付费的一年到几年。到期不续，浏览器就拦，用户看到警告就走。

我后来给这个客户做的，不是「记到日历里提醒自己」，那是靠人，人总会忘。我做的是让它自动续。

免费证书用certbot这类工具，装好之后配一条定时任务，让它每周检查一次，快到期就自动续。我一般让它每周跑，续期成功会自动reload nginx，用户那边完全无感。配好之后两年没再出过问题。

如果你用宝塔面板，里面有一键SSL和自动续期，勾选上就行，比手动省事。用云服务商的CDN或负载均衡，很多平台提供托管证书，自动续，连服务器都不用登。我把客户尽量往这条路上引——能交给机器做的事，别靠人记。

自动续期也要留个后手。我见过定时任务失效的情况：证书续期脚本报错，邮件通知没配，等过期了才发现。所以我一般再加一道监控：每周检查一次证书剩余天数，低于20天就发条消息到微信或邮箱。两道防线，一道自动续，一道盯结果。定时任务我自己也留了日志，每月翻一眼有没有续期失败的记录，省得脚本悄悄挂了没人知道。

还有个细节：一个域名下的证书可能不止一张。主域名、www、还有几个子域名，各有各的证书，别只盯着主域。我有个客户主域证书续了，mail子域的忘了，结果企业邮箱的网页登录也报证书错误。通配符证书能省不少事，一张管一片子域。

还有一种「看着有证书、实际还是报错」的情况：证书链不完整。浏览器提示「证书不受信任」，很多人以为装错了反复重装，其实是中间证书没配齐。用在线检测工具查一下，把完整证书链补上就好。我帮客户排查过一次，折腾半天，才发现少了一行中间证书。

证书这事，技术上没什么难度，拼的是「别忘」。把续期自动化、再加个监控，基本就能彻底忘掉它。你现在的证书是谁在管、多久到期、有没有自动续，最好现在就去确认一下，别等浏览器弹警告。

拿不准你的续期配置对不对，可以把细节发我，我帮你看看有没有漏。
