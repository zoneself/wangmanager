服务器被入侵的几个信号

服务器被入侵很少有人第一时间发现，多是别人先察觉。CPU半夜跑满、网站目录多出陌生php、登录日志有陌生IP、邮件发不出去——这几个信号花五分钟就能扫一遍。

发布于 2026-11-22 更新于 2026-11-25 王经理服务器与安全

服务器被入侵，很少有人第一时间发现。多数是别人先发现——客户打不开网站、百度快照变成博彩、云厂商发来告警邮件，才回头查。其实入侵之后会留下不少信号，只是没人去看。

我一年里帮客户救过几台机器，把常见的信号捋一捋，你平时留意这几个地方，能早半天甚至几天发现问题。

一个明显的信号是资源异常。CPU长期跑满、内存占用莫名其妙高、带宽半夜猛涨，都得警惕。有个做五金外贸的客户，有阵子网站慢得打不开，我上去看top，一个陌生进程CPU占满，进程名故意起得像系统服务。顺着查是挖矿程序，已经跑了一周多。还有一台机器，白天正常，一到夜里带宽跑满——被人当成攻击别的站的跳板。

另一个信号是网站目录里多了不该有的东西。我救站时常按修改时间排序看网站目录，找最近几天新出现的php文件。挂马的程序往往藏在 wp-content/uploads 这类上传目录里，文件名起得跟正常文件很像。有个站的后门藏在图片目录，伪装成jpg，打开其实是一段php。你只要定期看一眼「最近改过哪些文件」，多出来的基本藏不住。

再一个是登录痕迹不对。last命令能看谁在什么时候登进来过，留意陌生的IP和深夜的登录。再查一下 ~/.ssh/authorized_keys 里有没有你不认识的公钥——攻击者常留一把钥匙当后门，方便下次再来。crontab 也值得看一眼，挖矿程序爱在里面加定时任务，保证重启后还能自动跑。

还有个信号是邮件发不出去。网站订单邮件突然进垃圾箱，或者服务器发的信被拒，很可能是IP被拉进了黑名单——多半是这台机器被人拿去发过垃圾邮件。我有客户就是这么发现的：客户投诉收不到询盘回复，一查IP已经被几家反垃圾组织标记了。

这些检查都不难，top、last、看目录修改时间、看crontab，几分钟就能过一遍。怕就怕从来不看，等机器被拿去干坏事、IP被封了才发现。

还有个渠道别忽略：云厂商的安全告警。阿里云、腾讯云都有异常登录、暴力破解的告警，默认发邮件或短信，有人嫌烦关掉了，我建议留着。我有客户就是收到「检测到挖矿行为」的短信才知道机器出事的，比自己发现早了三天。

我给客户的建议是每周花五分钟扫一眼这几处，或者设个监控，资源异常时发条消息到微信。真发现不对，先别急着重启——重启会把内存里的痕迹冲掉，先把现场留下来，再来找我聊怎么清。

要是你怀疑自己的机器不太对劲，又不确定从哪查起，把现象描述给我，我帮你判断是不是真出了问题。
