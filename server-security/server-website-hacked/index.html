站被挂马了，我怎么救回来的

客户的站只在手机上跳博彩，电脑端正常。救站我最忌讳上来就删文件——没找准入口清完还会再中。我的顺序是留现场、切维护页、查日志找入口、清后门、改密码、再观察三天。

发布于 2026-11-23 更新于 2026-11-25 王经理服务器与安全

今年三月，一个做服装辅料外贸的客户找我，说他的站打开会跳转到博彩页面，而且只在手机上跳，电脑上正常。我用手机打开一看，确实跳了。这种「按设备跳」的挂马很常见——黑产要的是移动端的流量和转化，故意避开电脑端，让站长晚点发现。

救站这事，我最忌讳的是上来就删文件。很多人一看被挂马，第一反应是把最近改过的文件删掉、重装网站。这么做有两个坏处：一是没搞清楚入口，清完过两天又被挂；二是把现场破坏了，想查怎么进来的就查不到了。

我的顺序是这样的。先备份现场——整个网站目录和数据库打包下载一份，哪怕它是带毒的，留着排查用。然后把站点暂时下线或切到维护页，别让访客继续中招，也别让攻击者发现你在处理。

接下来找入口。我按修改时间把网站目录排一遍，重点看最近一两周新出现或改过的php文件。那次在 wp-content/uploads 里找到一个伪装成图片的php文件，文件内容是一段base64，就是它负责跳转。顺着这个文件的修改时间，我去翻服务器日志，找到了它被上传的那条记录——是通过一个两个月没更新的表单插件传上来的，那个插件有已知漏洞，客户一直没升级。

找准入口，才开始清。删掉后门文件，比对官网原版核对核心文件有没有被改，数据库里被插入的跳转代码也要清——有些挂马把代码写进数据库，光清文件没用。然后是该改的密码全改一遍：FTP、数据库、面板、WordPress后台，一个不落。再把那个有漏洞的插件更新或删掉。

清的时候我还顺手查一遍隐藏链接。有些挂马不只跳转，还在页面底部塞一堆博彩黑链，用CSS藏起来，肉眼看不见，搜索引擎抓得到。救站那次我在数据库里翻出二十多条，不删干净，排名照样被拖累。

收尾是观察。清完不等于结束，我让客户把网站先放三天，每天看日志、看目录有没有新文件。有些后门藏得深，清一次不一定干净，过几天又冒出来。三天内没动静，才算真的救回来。

整个活干下来花了大半天，临走时我把那台机器的面板密码和目录权限也一起收了一遍。客户问我能不能保证以后不再被挂。我说不能打包票，但把插件更新、密码改硬、目录权限收好，再把备份做扎实，再被挂的概率小很多——真再出事，也能半小时恢复，而不是像这次一样从头查到尾。

被挂马不丢人，丢人的是清完不知道怎么进来的，下次还从同一个门进。你要是遇到类似情况，先别急着删，把现象告诉我，我帮你理一下该怎么查。
