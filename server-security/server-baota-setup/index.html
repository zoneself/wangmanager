宝塔面板装完，先做这几件事

一个客户的站跳博彩，问题不在网站代码，在宝塔面板——8888端口开着，密码是admin123456。装完不做这几件事，等于把门敞开还挂张写着密码的纸条，出事后再补要大半天。

发布于 2026-11-20 更新于 2026-11-25 王经理服务器与安全

去年年底接了个急活。一个做灯具外贸的客户，网站突然跳到博彩页面，百度收录也全变了。我远程上去一看，问题不在网站代码，在宝塔面板——他装完面板就再没动过，8888端口开着，管理员密码是admin123456，登录日志里一晚上几百次尝试。

宝塔这类面板好用，装完就能建站、配SSL、看日志，中小企业老板自己也能上手。问题是默认配置是「方便优先」，不是「安全优先」。装完不做几件事，等于把家门敞开，还挂了张写着密码的纸条。

上来先改面板入口和端口。宝塔装完会给一个随机入口和8888端口，很多人图省事就用默认的。我在日志里见过攻击者批量扫8888端口的痕迹，一天几十次。到面板设置里把端口换成一个不常用的高位端口，把入口URL也改掉，能挡掉绝大部分无脑扫描。这不是高深技术，就是把门牌号藏起来。

面板最好再限一下来源IP。我自己的面板只允许办公室和家里的固定IP访问，别人就算知道端口和入口也连不上。没有固定IP的，只放行常驻城市的IP段，或者干脆只在要用的时候去安全组里临时开一下，用完关掉。有次我忘了关临时规则，面板端口对全网开了两天，日志里立刻多出几十次登录尝试，后来养成习惯用完就关。麻烦一点，但面板是服务器的大门，值得多费这一步。

接着把账号密码换成硬的。用户名别用admin，密码别用生日、公司名加123。我让客户用一个他记不住、但存在密码管理器里的长密码，再开两步验证。宝塔支持绑定微信或邮箱二次验证，点几下的事。那个灯具客户就是栽在弱密码上，改完之后再没出过类似问题。

然后收一收服务器端口。除了网站需要的80、443和你改过的面板端口，其他能关就关。SSH端口我一般也改掉，这个后面单独讲。云服务商的安全组和系统防火墙里都设一遍，两道门比一道稳。

登录失败锁定也别忘了。宝塔自带「登录失败次数限制」，设成错五次锁一小时，再配上fail2ban自动封IP，暴力破解基本没戏。那客户的登录日志里几百次尝试，就是没人管才一直试。

还有一件是检查默认站点和目录权限。装完面板常留着一个默认站点，用不上就删。网站目录给运行用户最小权限，别图省事给777——我见过有人全给777，被上传木马后到处都能写。

这几件事做完，面板就从「裸奔」变成「能看门」。那个客户我把面板入口改了、密码换了、失败锁定开了，又清了挂马代码，前后折腾大半天，花的钱比当初半小时做完这些事多得多。

你要是刚装完面板不确定从哪下手，照着这几条过一遍就行。拿不准的地方来问我，我告诉你具体点哪儿。
