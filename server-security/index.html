服务器与安全

服务器与安全一线经验：云服务器选择、宝塔面板配置、SSH 密钥、防火墙、入侵信号、证书过期、异地备份与网站被挂马的救站流程。

    防火墙规则，最小够用就行

    客户为了远程调试方便，把MySQL的3306端口对全网开放，两周内数据库被加密勒索。防火墙的原则就一句：默认全关，需要哪个开哪个，来源能限就限。安全组和系统防火墙都得设，改完还得从外网扫一遍。

    站被挂马了，我怎么救回来的

    客户的站只在手机上跳博彩，电脑端正常。救站我最忌讳上来就删文件——没找准入口清完还会再中。我的顺序是留现场、切维护页、查日志找入口、清后门、改密码、再观察三天。
