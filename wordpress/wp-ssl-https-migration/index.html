从http换到https，我踩过的坑

客户以为换 https 就是装个证书。我整套换下来踩了一串坑，后来写成一份检查清单，每次迁移都照着走。

发布于 2026-11-23 更新于 2026-11-25 王经理WordPress 实战

前年有个客户，站用了三年 http，找我说要换成 https。他说不就是加个证书吗，能有多难。我换完这一整套下来，踩了一串坑，后来写成了一份检查清单，每次迁移都照着走。这事真不是装个证书就完事。

第一个坑：换完证书，浏览器还是显示「不安全」。原因往往是页面里还有 http 的资源没改过来，图片、脚本、样式表还写着 http 的绝对地址，浏览器就判定这个页面不是全 https。我那客户首页有几十张产品图，全是 http 开头，一张张改到手酸。后来我学乖了，迁移前先用工具全站扫一遍 http 链接，批量替换成 https，或者干脆改成相对路径。

第二个坑：换完之后排名掉了。百度和 Google 都把 https 当成排名信号，本来换成 https 应该是好事，但如果你只是简单换了个地址，没告诉搜索引擎，它会当成两个不同的站，权重分散，排名一乱就是几周。正确的做法是配置 301 永久重定向，把 http 的访问全部跳到 https，然后在搜索资源平台提交改版规则。这一步很多建站的人不做，客户也不知道，等排名掉了才来找我们。

第三个坑：表单和支付收不到通知。有些表单插件、支付接口回调地址写死成了 http 的，站换成 https 后，回调过不来，询盘和订单就丢了。这个坑最隐蔽，因为前台看着一切正常，老板根本不知道自己在丢单。我现在的习惯是，迁移完一定手动测一遍表单提交和支付流程，确认邮件能收到、订单能进来，才算完工。

第四个坑：证书过期没人管。免费证书一般三个月到期，你不管它，到期那天全站浏览器告警，客户一看红色警告就跑了。我给客户都设了自动续期，或者干脆用能自动续的托管证书，这事不能靠人记。

换 https 是迟早的事，早换早省心。但你要找人换的话，把上面这几个坑拿去问他怎么处理，答不上来的，慎找。你要是正在迁移中卡住了，把现象告诉我，我帮你看看卡在哪一步。
